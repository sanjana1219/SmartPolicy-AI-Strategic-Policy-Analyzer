# SmartPolicy-AI-Strategic-Policy-Analyzer
SmartPolicy AI is an AI-powered web application designed to analyze policy documents and generate intelligent, context-aware insights. It helps users understand complex policy documents quickly through summarization, scenario adaptation, and interactive chatbot responses.


Key Features

*  Upload PDF policy documents
* AI-powered policy summarization (Google Gemini)
*  Scenario-based adaptation:

  * Public Awareness
  * Budget-Constrained
  * Emergency Response
* Conversational chatbot for policy Q&A
* Interactive dashboard built with Streamlit


System Architecture

* **Frontend:** Streamlit dashboard
* **Backend:** Google Gemini AI (LLM)
* **Processing:** PyMuPDF (PDF text extraction)
* **Session Management:** Streamlit session state


Tech Stack

* Python
* Streamlit
* Google Gemini AI
* PyMuPDF
